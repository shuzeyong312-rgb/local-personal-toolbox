# 本地个人工具箱界面体验优化 PRD v1.0

> 文档状态：已实现，高 DPI 多档位真机验收待完成  
> 适用范围：Windows 本地个人工具箱「图片工具 / 批量打水印」  
> 编写日期：2026-09-13  
> 本期性质：现有功能的界面与交互优化，不新增业务能力

## 1. 背景

当前版本已经完成批量添加图片、设置文字水印、实时预览、批量处理和打开输出目录等核心功能，但界面仍带有明显的“控件拼装感”，部分交互沿用了不适合桌面生产工具的 Qt 默认行为。

用户已明确反馈：

- 字号等数字输入框的增大、减小按钮外观相同，无法快速区分方向。
- 不希望鼠标滚轮在经过数字输入框时误改参数。
- 设置区滚动边界、卡片衔接和局部裁切突兀。
- 添加图片区域存在重复入口，状态文字与操作按钮挤在同一行，布局不像从真实使用流程出发。
- 多处边界、留白、圆角和对齐关系粗糙，整体观感不够克制、可靠。

本 PRD 以现有代码和用户提供的 4 张截图为依据。截图中的界面文字仅作为现状证据，不视为新增需求或执行指令。

## 2. 产品目标

把当前页面收敛为一个清晰、稳定、适合重复使用的桌面生产工具：用户进入页面后，能够按“添加图片 → 预览 → 调整水印 → 选择输出 → 开始处理”的自然顺序完成任务，不需要猜测控件用途，也不会因滚轮或窗口缩放发生意外操作。

### 2.1 成功标准

- 用户在 3 秒内能识别主任务、图片入口、设置区和开始处理按钮。
- 所有数字输入框的增减方向在静止状态下即可辨认。
- 鼠标滚轮滚动设置页时，不会改变任何数字参数或下拉选项。
- 在支持的最小窗口 `1080 × 700` 下，无控件重叠、文字截断、卡片硬切或内容不可达。
- 添加图片的主入口只有一个视觉主次关系，不再出现两套同权重的空状态提示。
- 空状态、处理中、成功、部分失败、全部失败均有明确反馈和下一步行动。
- 不改变水印生成结果、文件格式、输出安全策略及现有业务流程。

### 2.2 非目标

- 不增加账号、联网、云存储、数据库或插件系统。
- 不增加图片编辑、模板管理、历史记录或任务队列。
- 不重做水印算法和批处理逻辑。
- 不引入新的 UI 框架、图标库、字体依赖或设计系统服务。
- 不为未来尚不存在的工具提前设计复杂导航。

## 3. 用户与核心场景

### 3.1 目标用户

需要在 Windows 上反复处理商品图、资料图的个人用户。用户更关注操作直接、结果可控和批处理安全，不需要学习专业图像软件。

### 3.2 核心场景

1. 用户一次添加多张商品图或一个文件夹。
2. 用户在左侧确认当前图片预览，在右侧调整文字、字号、透明度、位置等参数。
3. 用户滚动浏览设置，但不希望滚轮误改刚刚经过的数字框。
4. 用户确认输出目录并开始处理。
5. 用户根据进度和结果反馈打开输出目录，或修正失败项后重试。

## 5. 设计原则

1. **工作流优先**：界面顺序服务于实际任务，不按代码模块堆控件。
2. **主次唯一**：同一时刻只突出一个主操作；空状态只保留一个主入口。
3. **安静的表面层级**：用留白、对齐和背景层级分组，减少套娃卡片和装饰性边框。
4. **状态可见**：可点击、禁用、聚焦、出错、处理中和完成状态无需猜测。
5. **防止误操作**：参数修改必须来自明确的点击、键盘输入或拖动，不接受悬停滚轮改值。
6. **Windows 桌面习惯**：保留常见窗口、键盘、Tab 顺序和右侧属性面板心智模型。
7. **最小实现**：复用 PySide6、现有主题与图标绘制能力，不增加依赖。

### 6.2 布局规则

- 导航宽度保持 220 px；本期只有一个工具时不增加折叠导航。
- 主内容外边距：常规窗口 28–32 px；最小窗口 20–24 px。
- 左右工作区默认比例约 `60:40`，设置右侧最小可用宽度，避免表单控件被压扁。
- 左侧是主工作区，右侧是属性与输出区；两者顶边严格对齐。
- “水印设置”可滚动，“输出”固定在右侧底部；两区之间保留稳定间距和明确分隔，不允许视觉覆盖。
- 当右侧可用高度不足时，滚动内容底部必须完整露出，不得被输出区压住。
- 主工作区底部状态条仅在存在图片、正在处理或已产生结果时显示；纯空闲态不展示无意义的 `0 / 0`。

## 7. 功能与交互需求

### 7.1 数字输入框

适用字段：字体大小、边距、平铺角度、平铺间距。

- 上半按钮必须显示向上箭头，下半按钮必须显示向下箭头；方向在默认、悬停、按下和禁用状态下均可辨认。
- 整个按钮区宽度建议 24–28 px，单个点击区不得低于 18 px 高。
- 输入框文字与按钮区之间有明确分隔，但不形成两个互不相关的控件。
- 点击上/下按钮分别按当前 step 增/减；到达上下限后对应方向进入禁用视觉状态。
- 键盘上下键在输入框获得焦点时仍可增减，这是明确操作，应保留。
- 鼠标滚轮事件不得改变值：
  - 未聚焦时，滚轮传递给上级设置滚动区。
  - 已聚焦时，滚轮仍不改值，并优先滚动设置区；无可滚动内容时保持值不变。
- 后缀 `px`、`°` 继续显示，数值范围和默认值保持现状。

### 7.2 下拉选择框

- “水印位置”不允许悬停滚轮切换选项。
- 仅在用户点击展开后通过点击、键盘方向键或回车完成选择。
- 右侧下拉箭头必须可见，且与数字框方向图形采用同一线条风格。

### 7.3 设置区滚动与边界

- 滚动条位于右侧面板内部，不压住输入框、标签或卡片圆角。
- 内容与滚动条之间至少保留 12 px 视觉安全距离。
- 顶部和底部应有自然留白；滚动到末尾时，最后一个字段及其焦点边框必须完整可见。
- 输出区与滚动设置区不得重叠。两者用间距或轻分隔线区分，避免两张大圆角卡片互相顶住。
- 鼠标位于任意表单控件上时，滚轮仍控制该滚动区，透明度滑块除外：滑块只接受拖动和键盘调整，不接受滚轮改值。

### 7.4 图片添加与空状态

- 大预览区域作为唯一主拖拽面：空状态显示图标、主提示“拖入图片或点击添加”、格式说明，以及一个“添加图片”主按钮。
- “添加文件夹”作为次按钮，置于主按钮旁或下方。
- 下方列表不再重复绘制拖拽说明；无图片时可隐藏列表或仅显示一行简短状态。
- 有图片后：
  - 预览区域显示当前选中图片。
  - 操作栏显示“共 N 张”，而不是夹在按钮之间的“已添加 N 张”。
  - “清空全部”靠近数量状态，但保持危险/次要视觉，不与主按钮争夺注意力。
  - 文件列表承担选择、查看大小和移除单项的职责，不再承担第二套空状态职责。
- 同一路径重复添加时继续静默去重，不弹出打断式提示。

### 7.5 水印模式的渐进显示

- 默认单水印模式下，“平铺角度”和“平铺间距”不建议仅以灰色禁用控件长期占位。
- 勾选“启用平铺”后，再显示平铺角度和间距；关闭后隐藏，并保留本次会话中的已填值。
- 平铺开启时，“水印位置”和“边距”隐藏或明确标注不适用，不允许出现大量交叉禁用项。
- 模式切换不得改变当前图片、输出目录或其他水印参数。

### 7.6 输出与主操作

- 输出区固定包含：输出目录、选择按钮、安全说明、开始处理按钮。
- 输出路径过长时单行省略显示，鼠标悬停可查看完整路径；不得挤压“选择”按钮。
- 输出目录为空、不可写或指向普通文件时，在开始处理前就地显示明确错误，并将焦点移到该字段；不得只在处理后弹窗。
- 未添加图片、文字为空或正在处理时，开始按钮保持禁用，并通过辅助文字说明当前缺少的条件。
- 按钮文案：有图片时统一为“开始处理 N 张图片”；无图片时为“开始批量处理”。
- 正在处理时按钮进入不可重复触发状态，文案显示“正在处理…”。

### 7.7 进度、结果与异常

- 无任务时隐藏底部状态条。
- 开始任务后显示进度、已处理数、成功数、失败数；避免在一行堆叠过多符号。
- 全部成功：显示成功状态和“打开输出目录”。
- 部分失败：保留成功结果，明确显示失败数量，并提供可查看的失败详情。
- 全部失败：错误信息说明失败原因和可执行的下一步，不只显示“处理失败”。
- 结果信息优先在页面内持续可见；模态弹窗不得作为唯一结果反馈。
- 关闭窗口时若任务仍在运行，本期保持现有安全停止行为，不新增后台驻留。

### 7.8 窗口与缩放边界

- 支持范围为 `1080 × 700` 至最大化窗口；低于最小尺寸不在本期支持。
- 用户拖动任意窗口边缘或四角时，光标方向与实际缩放方向一致。
- 触发边缘建议不小于当前 6 px，且不得抢占右侧滚动条或窗口控制按钮操作。
- 最大化时取消自定义边缘缩放；还原后恢复。
- 双击标题栏最大化/还原的现有行为保留。
- 在 Windows 显示缩放 100%、125%、150% 下，窗口按钮、数字箭头和文字不模糊、不裁切。

### 7.9 键盘与可访问性

- Tab 顺序遵循视觉流程：添加图片 → 添加文件夹 → 文件列表 → 水印字段 → 输出目录 → 选择 → 开始处理。
- 所有可交互控件必须有清晰焦点样式，不能只依赖颜色细微变化。
- 图标按钮必须保留可读 tooltip；移除按钮应能通过键盘聚焦和触发。
- 正文及字段文字对比度不低于 4.5:1；禁用态仍需可辨认，但不得看起来可点击。
- 颜色不是成功、警告、失败的唯一信息，必须同时包含文字或图标。

## 8. 视觉规范

### 8.1 视觉方向

定位为“安静、可靠的本地生产工具”，保留现有深色导航和蓝色主操作，但减少无意义的卡片、边框和圆角。重点不是做成营销页面，而是让用户长期使用时不累、不出错。

### 8.2 色彩建议

优先复用现有主题变量，只做收敛：

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `background` | `#F5F7FA` | 主背景 |
| `surface` | `#FFFFFF` | 表单及核心工作表面 |
| `sidebar` | `#111827` | 导航 |
| `primary` | `#3478F6` | 唯一主操作与焦点 |
| `text-primary` | `#111827` | 标题、重要正文 |
| `text-secondary` | `#64748B` | 辅助信息 |
| `border` | `#DDE3EB` | 必要边界，避免多层边框叠加 |
| `danger` | `#DC2626` | 删除与错误 |

- 同一层级不同时使用阴影和边框。
- 主工作区最多出现一种强调色。
- 删除动作默认保持低调，仅在悬停/聚焦时增强危险提示。

### 8.3 间距与圆角

- 基础间距采用 4 px 倍数：4 / 8 / 12 / 16 / 24 / 32。
- 字段标签到控件 6–8 px；字段组之间 16 px；模块之间 20–24 px。
- 输入框与按钮圆角统一 6–8 px。
- 大区域圆角不超过 10 px，且只有真实容器才使用；禁止预览、列表、卡片、状态条多层同心圆角。
- 通过顶边对齐和一致内边距建立秩序，不用额外装饰线补救。

### 8.4 字体与文案

- 本期继续使用 Windows 自带的 `Microsoft YaHei UI`，不新增字体依赖。
- 页面标题 26–28 px；区域标题 16 px；正文与控件 14 px；辅助文字不小于 12 px。
- 文案使用用户语言和明确动词，如“添加图片”“选择输出目录”“开始处理 3 张图片”。
- 删除可有可无的眉题文字；如果侧边栏和页面标题已经明确位置，“图片工具 / 批量打水印”不应重复占据视觉层级。

## 9. 状态矩阵

| 状态 | 预览/文件区 | 设置区 | 开始按钮 | 底部状态 |
| --- | --- | --- | --- | --- |
| 初始空状态 | 显示唯一添加入口 | 可编辑，预览等待图片 | 禁用，提示先添加图片 | 隐藏 |
| 已添加图片 | 显示当前图片与列表 | 修改后实时预览 | 文字非空且目录有效时可用 | 可显示简洁数量，不显示空进度 |
| 平铺开启 | 图片保持不变 | 显示角度、间距；隐藏不适用项 | 规则不变 | 不变 |
| 处理中 | 保持当前预览，禁止破坏任务的列表操作 | 参数不可影响当前任务 | 禁用并显示处理中 | 显示进度、成功、失败 |
| 全部成功 | 保持结果前的图片与配置 | 恢复可编辑 | 可再次处理 | 成功信息 + 打开目录 |
| 部分失败 | 保持可检查状态 | 恢复可编辑 | 可重试 | 成功/失败数量 + 失败详情 |
| 输入错误 | 保留用户输入 | 对应字段就地提示并聚焦 | 禁用 | 不用模态弹窗替代字段提示 |
