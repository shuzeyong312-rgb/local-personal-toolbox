# 图片格式转换功能 PRD V1.0

## 1. 功能目标

在现有个人工具箱中新增「图片格式转换」功能，用于批量将图片转换为指定格式。

主要使用场景：

* WebP → PNG
* PNG → JPG
* JPG → PNG
* JPG / PNG → WebP
* BMP → JPG / PNG
* 电商素材批量统一格式
* 将不兼容平台的图片转换为常用格式

设计原则：

**简单、批量、稳定、尽量避免不必要的画质损失。**

---

# 2. MVP 支持格式

## 输入格式

第一版支持：

* JPG / JPEG
* PNG
* WebP
* BMP

## 输出格式

支持：

* JPG
* PNG
* WebP
* BMP

暂不支持：

* GIF
* TIFF
* HEIC / HEIF
* AVIF
* SVG

这些格式后续根据实际需求增加，避免第一版引入额外依赖和兼容问题。

# 3. 页面结构

页面整体沿用当前工具箱统一 UI 风格。

页面分为四个区域：

### ① 文件选择

支持：

* 添加图片
* 添加文件夹
* 拖拽导入
* 清空列表

文件列表显示：

* 文件名
* 当前格式
* 图片尺寸
* 文件大小
* 状态

例如：

```text

商品主图02.png     PNG     800×800    1.2MB
```

---

### ② 转换设置

核心设置：

**目标格式**

下拉选择：

```text
PNG
JPG
WebP
BMP
```

默认记住用户上一次选择。

---

### ③ 画质设置

仅针对存在有损压缩的格式显示。

#### JPG

显示：

```text
图片质量
[ 90 ]
```

范围：

```text
1–100
```

默认：

```text
90
```

推荐区间：

```text

```

#### WebP

提供：

```text

○ 无损模式
```

默认：

```text
高质量压缩
质量 90
```

PNG / BMP 不显示质量设置。

# 4. 透明背景处理

这是必须处理好的重点。

当：

```text
PNG / WebP透明图 → JPG
```

由于 JPG 不支持透明背景，需要自动处理透明区域。

增加设置：

```text
透明区域背景：

● 白色
○ 黑色
○ 自定义颜色
```

默认：

```text
白色
```

避免透明图片转换 JPG 后出现黑底。

---

# 5. 文件名规则

默认保持原文件名。

例如：

```text
暖手宝主图.webp
```

转换后：

```text
暖手宝主图.png
```

提供可选：

```text
文件名前缀：
[            ]

文件名后缀：
[            ]
```

例如填写：

```text
前缀：转换版_
```

结果：

```text
转换版_暖手宝主图.png
```

默认不添加任何前后缀。

---

# 6. 同名文件处理

如果输出目录存在同名文件：

默认：

```text
自动添加序号
```

例如：

```text
主图.png
主图_1.png
主图_2.png
```

不要默认覆盖原文件。

可提供：

```text
同名文件处理：

● 自动重命名
○ 覆盖文件
○ 跳过文件
```

默认：

```text
自动重命名
```

输出位置：

● 原文件所在目录
○ 指定输出目录

指定输出目录

# 8. 图片尺寸

格式转换默认：

**不得改变图片尺寸。**

例如：

```text
原图：1500 × 1500
转换后：1500 × 1500
```

图片尺寸调整应由独立的「批量修改图片尺寸」工具完成。

避免两个功能职责重叠。

---

# 9. EXIF / 元数据

第一版建议默认：

```text
不主动保留 EXIF 元数据
```

主要原因：

* 电商图片一般不需要 EXIF
* 可以减少文件体积
* 避免方向、相机信息等带来的兼容问题

后续可增加：

```text
□ 保留图片元数据
```

但不纳入 MVP。

# 12. 转换逻辑

推荐使用：

```text
Pillow
```

作为主要图片处理库。

基本转换流程：

```text
读取图片
↓
识别原始格式
↓
读取颜色模式
↓
处理透明通道
↓
转换目标颜色模式
↓
按目标格式保存
↓
验证输出文件
```

# 13. 颜色模式处理

程序必须自动处理：

```text
RGB
RGBA
P
L
CMYK
```

例如：

PNG RGBA → JPG：

```text

↓

↓

↓

```

```text

```

等错误。

# 14. 画质原则

必须明确：

**格式转换不能保证完全无损。**

情况：

### PNG → PNG

基本无损。

### PNG → JPG

一定存在有损压缩，同时透明通道会丢失。

### JPG → PNG

不会恢复 JPG 已经损失的画质。

只是：

```text
JPG内容 → PNG容器
```

图片质量不会变得更清晰。

### WebP → PNG

如果原 WebP 本身是有损压缩：

转换 PNG 后也无法恢复已经损失的信息。

### PNG → WebP

选择无损 WebP 时可以基本保持原始图片质量。

因此软件不要出现：

```text
无损转换
```

这种容易误导用户的宣传文字。

# 15. 记住上次设置

需要保存：

* 上一次目标格式
* JPG质量
* WebP质量
* WebP无损模式
* 透明背景颜色
* 输出目录
* 同名文件处理方式

下次进入工具时自动恢复。

---

# 17. 异常处理

以下情况不能导致程序崩溃：

* 文件损坏
* 文件后缀与实际格式不一致
* 图片无法读取
* 输出目录不存在
* 输出目录无权限
* 磁盘空间不足
* 同名文件
* 超大图片
* RGBA → JPG
* CMYK JPEG
* 用户中途取消

单个文件失败时：

```text
记录失败
继续处理剩余文件
```

不能整个任务直接终止。

---

# 18. 第一版明确不做

V1 不加入：

* 图片压缩
* 图片尺寸修改
* 图片裁剪
* DPI 修改
* EXIF 编辑
* GIF 动图转换
* HEIC
* AVIF
* SVG
* AI 超分辨率
* 图片增强

这些功能不要混入格式转换工具。

保持单一职责：

> 图片格式转换只负责「格式转换」。

---

# 19. 验收标准

功能完成必须满足：

1. 可批量导入图片
2. 可批量导入文件夹
3. 支持 JPG / PNG / WebP / BMP
4. 可选择目标格式
5. JPG 可设置图片质量
6. WebP 支持质量设置和无损模式
7. PNG透明图转换 JPG 不出现黑底
8. 图片转换后尺寸保持不变
9. 不修改原始图片
10. 同名文件默认自动重命名
11. 支持指定输出目录
12. 自动记住上一次设置
13. 任务执行使用统一进度弹窗
14. 单个文件失败不会影响整个任务
15. 完成后显示成功 / 失败数量
16. 可直接打开输出目录
17. UI 与现有工具箱保持一致

---
